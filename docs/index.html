DESIGN NOTES

Keva — a distributed key-value store

Keva is a strongly consistent, distributed key-value store written in Go, replicated with the Raft consensus algorithm. These docs record the design decisions chapter by chapter, as the system is built from the ground up.

The build order is deliberate: make each layer correct in isolation before adding the next. Storage is proven in memory behind an interface, then made durable, then replicated. Each chapter maps to a phase of that build.
